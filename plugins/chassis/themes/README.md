# Bundled themes

All 615 schemes from https://github.com/mbadolato/iTerm2-Color-Schemes at commit 6856029b0009a2f7bbeffad56183c234971a84e7, converted with the shared theme importer. Binary plists are converted to XML with Python plistlib before importing.

The collection license is in ITERM-COLOR-SCHEMES-LICENSE. Catppuccin attribution is additionally retained in CATPPUCCIN-LICENSE. Source colors and names are preserved; QM derives interface colors at runtime.
